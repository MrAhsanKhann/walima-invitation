WALIMA DIGITAL INVITATION

1. Open index.html in a browser to preview the invitation.
2. To send RSVPs directly to Malik Waqar, open index.html in a text editor and find:
   const HOST_WHATSAPP_NUMBER = "";
   Enter the WhatsApp number with country code and digits only, e.g. 923001234567.
   If left blank, the RSVP button opens WhatsApp's share flow with the message prefilled.
3. Publish the folder using Netlify Drop (https://app.netlify.com/drop) or upload it to a GitHub repository and enable GitHub Pages.
4. Share the published URL with guests.

The background chime is generated in-browser using the Web Audio API. It starts only after a visitor presses Play, as browsers block autoplay by default.
